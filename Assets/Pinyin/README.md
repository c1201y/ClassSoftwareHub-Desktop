# 拼音对照表

`pinyin.tsv` 是提交向导把软件名转成软件 ID 用的对照表，每行一个汉字：

```
网	wang
易	yi
```

## 来源与许可

- 数据：npm 包 `pinyin-data@1.0.0` 的「全拼数据.js」（<https://github.com/program-in-chinese/npm-pinyin-data>），ISC 协议。
- 处理：收 GB2312 可编码的 6,763 个常用字，另收包内 853 条多音字词（`音乐` → yinyue、`银行` → yinhang）用于最长匹配；
  多音字取第一个读音；去掉声调；`ü` 统一写作 `v`。
- 生成于 2026-11-12。原始包约 313 KB，筛完 67 KB（7,616 行），作为内嵌资源随程序发布。

## 重新生成

1. 取 `https://unpkg.com/pinyin-data@1.0.0/全拼数据.js`。
2. 用脚本按 `"字":"pīn,yīn"` 提取单字，去声调、取首读音，只留 GB2312 字集。
3. 输出为 `<字>\t<拼音>`，按字排序，LF 换行、UTF-8 无 BOM。

表里没有的字（生僻字、繁体）在生成 ID 时直接跳过，不会报错；名称全是生僻字时 ID 留空，由用户手填。
