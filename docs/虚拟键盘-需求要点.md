## 〇、三条重要纠正（2026-09-30 21:47，Nick 看完整理稿后亲口纠正）

> 这三条推翻了我之前的理解，**重写时以此为准**。

| # | ❌ 我原来的理解 | ✅ 正确的要求（原话） |
|---|---|---|
| 1 | "对齐 WinUI 3 Gallery 的原生**观感**"（=照着模仿） | 「**不是要模仿 windows 原生，我就是要 windows 原生**」—— 意思是用**系统控件本身**做出原生效果，而不是自己画一个像原生的东西。「**颜色就用主题色就行了**」「你全程基本上都在自己画，那么多的系统控件你都不用」 |
| 2 | 弹出"**不挑输入来源**"（手指/笔/鼠标/UU 远程都认） | 「**为什么鼠标也要弹出这个虚拟键盘？**」—— 鼠标**不该**弹。（我当时是为了照顾 UU 远程才放开的，方向错了） |
| 3 | 键盘设置放**设置页**一整个分区 | 「把所有的相关设置之类的**全部迁移到实验性功能**」—— 键盘属实验性功能，入口与设置都归到那一组；并「**在侧面栏里面也加入一个打开键盘组件**」 |

**第 1 条的参照物**（Nick 亲自举的例子）：「就像最开始我之前不是叫你应用的设置页吗？**改半天都不好看，还不是系统的好看**。」
→ 即当初设置页从**自绘 `Border` 行**换成系统 **`SettingsCard`** 才好看。同一个道理套到键盘上。

## 一、定位

| 项 | 要求 |
|---|---|
| 是什么 | 自绘一套虚拟键盘，取代系统触摸键盘（TabTip）的使用体验 |
| ⛔ 不是 | 不是取代「屏幕键盘 OSK」（辅助功能里那个） |
| ⛔ 也不是 | 不是"换回系统键盘"—— 是**自己做一个**，但外观与手感要就是系统原生那个样子 |
| 平台 | Win11 + Win10，**重点 Win10**（Nick 自己实测） |
| 观感基准 | ⛔ 不是"模仿"，是**直接用系统控件 + 主题色**（见第〇节第 1 条、第四节） |
| 任务栏图标 | 点任务栏触摸键盘图标 → 期望弹我们的键盘。⚠️ 最新 Win11 已把触摸键盘写进内核，**这条暂时放弃**，待老版本 Windows 验证 |

## 二、入口与设置归属（2026-09-30 21:47 新增）

1. **所有键盘相关设置，全部放进「实验性功能」分组**，⛔ 不再占用设置页。
2. **侧边栏加入一个「打开键盘」组件** —— 一键呼出键盘（`Kind = Action`）。
3. 键盘本身作为「实验性功能」分组下的一个条目（`Tag="experimental"`）。
   ⚠️ 加功能要动三处：`Page.All` / `ShellPage.xaml` 分组子项 / `NavigateTagCore` 的 case。
   ⚠️ 侧边栏加模块**必须同时抬 `AppSettings.SidebarModulesRevision`**，否则老用户看不到（且不能让用户删掉的模块被塞回来）。

## 三、功能需求

### 3.1 弹出 / 收起

1. ⛔ **只有真触摸才弹，鼠标一律不弹**（见第〇节第 2 条）。
   ⚠️ **未决**：UU 远程那种"手机触摸 → 注入到 PC"的场景，Nick 之前要求它要能弹。若它注入的是鼠标事件，则与本条冲突 —— **需实测后定**。
2. 点键盘自己身上 **不能**触发"自收"。
3. 在我们自己进程的界面上操作（例如在实验性功能里调键盘外观）**键盘不能被收掉**。
4. ⛔ 不许"莫名其妙弹出来"。原话：「即使我使用的是什么键鼠之类的，关闭在触摸弹出的设置，它也会莫名其妙的弹出来，我气笑了」。

### 3.2 布局

5. **完整 / 精简两种模式**，像 Windows 原生那样可切。
6. ⛔ **默认必须是「完整」**。原话：「我不是教你使用系统的布局吗，你到底是出于什么目的呃，为什么会精简成这个样」。完整 = 与系统键盘一致的按键集合。
7. ⛔ **符号、数字必须能直接切**，不许"还得再去设置里点"。做法：键盘上自带层切换键（`&123` / `ABC`）。

### 3.3 贴靠 / 悬浮

8. **贴靠**：吸在屏幕边缘（最基本能力）。
9. **悬浮**：能在屏幕上**自由调节位置**，跟我们的悬浮工具一个意思。
10. ⛔ 拖动必须**跟手、不飘**（原话：「拖动起来卡卡的给我乱飘」）。

### 3.4 自定义（Nick 强调"一点也不丰富"、"要真的完全可控"）

11. **大小** —— 连续可调，⛔ 不是给几档固定值（原话：「它是真的能自定义完全可控的，不是你指定大小」）。
12. **键盘背景** —— ⚠️ 但见第〇节第 1 条：「颜色就用主题色就行了」→ **底色默认跟随主题**，不做自定义配色盘。
13. **键盘上的文字大小** —— 连续可调（这是**字号**，与"配色"不同，保留）。
14. 候选区文字大小 —— ⚠️ 当前设计里没有"候选区"，**待确认是否需要做**。

### 3.5 按键反馈

15. ⛔ **按下立刻有反馈**，抬起后要留住可见效果。原话：「我按一下这个虚拟键盘是没有反馈的，我要长按它才会变成蓝的」。

### 3.6 顶栏

16. 右上角按钮要**就是系统那个样子**。原话：之前那三个选项「真的很一般很没有设计感」。

## 四、样式要求 —— 用系统控件，别自己画

- ⛔ **不要自绘控件**。原话：「你全程基本上都在自己画，那么多的系统控件你都不用」。
- ⛔ 不要「粗糙劣质的网页感」。原话：「整个窗口看起来感觉就很粗糙劣质的网页感，根本和 WinUI 3 这个系统的看得很不相似，妈的割裂感像东非大裂谷」。
- ✅ **颜色一律走主题画刷**（`ControlFillColor*` / `TextFillColor*` / `SolidBackgroundFillColor*` 等），⛔ 不写死 RGB、⛔ 不自己造调色板。
- ✅ 各控件**优先用系统现成控件**：
  - 键帽 → `Button`（要锁住状态的如 Shift / Caps / Ctrl → `ToggleButton`）
  - 设置项 → `SettingsCard` / `SettingsExpander`（⛔ 不退回自绘 `Border` 行）
  - 下拉 / 滑块 / 开关 → 系统 `ComboBox` / `Slider` / `ToggleSwitch`
- **动画要跟手、层级关系要正确**。原话：「这个层级就很有问题，而且什么动画各种都非常的卡顿」。

## 五、⛔⛔ 硬性约束（用一次事故换来的，违反就是第二次事故）

| # | 约束 | 违反的后果（实测） |
|---|---|---|
| 1 | **永不杀 `TabTip.exe`** | 它就是 Win+H 的执行体。当时 1.5s 一轮盯杀，**一分钟杀 7 个** ⇒ **Win+H 直接失效**，表现为"时好时坏" |
| 2 | **尽量不写注册表**；非写不可时必须有备份 + 退出还原 | 上次改了 `TabletTip\1.7` 和 `InputMethod\Settings\Common` 两个值 |
| 3 | **全局鼠标钩子只在键盘可见期间装，钩子里只许记数据** | 钩子 = 全系统每个鼠标事件都过我们进程，我们一忙**整台机器卡** |
| 4 | **show / hide 必须去抖 + 最短驻留** | 当时两条来路互相触发，成了每 200ms 一轮 show/hide（日志：显示 95 次 / 收起 72 次） |
| 5 | 验收"接管系统输入"类功能，**必须检查它对系统其他部分的副作用**（Win+H、任务栏图标、输入法切换） | 只看"我的键盘弹没弹"会漏掉上面全部 |

**一句话原则：零侵入。** 键盘只在该出现的时候出现，不抢系统的东西、不杀系统的进程。

## 六、已知技术要点（真金白银，别再踩）

- ⛔ 键盘窗口**绝不能加 `WS_EX_NOACTIVATE`** —— WinUI 3 会完全不派发 `PointerPressed`。只加 `WS_EX_TOOLWINDOW` + `SW_SHOWNOACTIVATE`，每键先还前台再 `SendInput`。
- ⛔ **白边 = DWM 画的非客户区边框**：`SetBorderAndTitleBar(false,false)` **不等于**去掉 `WS_CAPTION / WS_THICKFRAME`。要 `WS_POPUP` + `SWP_FRAMECHANGED` + DWM 属性 33/34/**37**/38，**显示之后还要再调一次**。
- ⛔ 验"窗口外那一圈"**必须屏幕实拍** —— `PrintWindow` 抓不到 DWM 非客户区，上次拿离屏截图说"没白边"是**验证方式错**。
- ⛔ `ToggleButton` 与 `Button` 是**兄弟**（都继承 `ButtonBase`），按 `Button` 存编译不过。
- ⛔ 系统 `Button` 默认 `MinWidth=120`，不清零会把 Star 分列的整盘撑爆。
- ⛔ 拖动**别自己算 `PointerMoved`**（卡、飘）→ `ReleaseCapture()` + `SendMessage(WM_NCLBUTTONDOWN, HTCAPTION)` 交系统合成；位置从 `AppWindow.Position` 读回来再存。
- `INPUT` 结构在 x64 是 **40 字节**。
